# Chemistry notes: chapters 6-14

Thai chemistry study summaries with equations rendered from LaTeX using embedded MathJax 3.2.2 and mhchem.

Open index.html to select a chapter. Each chapter is self-contained and can also be read offline. Source lecture page references appear inside the notes.

## GitHub Pages

Publish the main branch from the repository root. The entry page is index.html. The .nojekyll file enables direct static-file publishing.
